# Dataset v1

The paper's dataset. What it contains, what changed from v0, what the audit found, and the
two outliers worth knowing about.

Generated by `scripts/generate_dataset.py --setting v1`, audited by `scripts/audit_dataset.py`.
Data: `outputs/dataset_v1/` (35.1 MB). Audit: `outputs/dataset_v1/audit.json`.
Setting: [PROBE_V1.md](PROBE_V1.md), decisions [D044–D046](DECISIONS.md#d044).

---

## 1. Shape

| | Dataset v1 | Dataset v0, for comparison |
|---|---|---|
| hidden states | **512**, scrambled Sobol over `[m, µ_s, ratio, b]` | 512, same sampler and seed |
| probe episodes | **1 536** — 3 independent repeats each | 1 536 |
| candidate rows | **49 152** — 32 forces per probe | 49 152 |
| probe | **fixed budget, 3.5 N over 0.3 s** | response-terminated ramp |
| probe history lengths | **18 steps, every single probe** | 6–56 steps, 41 distinct values |
| task | `d_goal = 100 mm`, `T = 1.5 s` | `d_goal = 40 mm`, `T = 1.5 s` |
| candidate range | 0.5–6.5 N, stratified, label-independent | 0.15–4.5 N |
| `reach_success` rate | **5.95 %** (2 926 rows) | — (v0 predates the split) |
| strict `success` rate | **0.00 %** | 6.54 % |
| invalid rate | **10.12 %** (4 974 rows) | 0.88 % |
| on disk | 35.1 MB, normalised | 29.5 MB |
| generation | 1 930 s (32 min), 32 environments | 2 103 s |

The **one distinct history length** is the fixed-budget probe's whole point, and it is now
measured rather than argued: 1 536 of 1 536 probes ran 18 steps and terminated with
`duration_completed`. Nothing downstream has to condition on when the probe happened to stop.

## 2. The two rates that look alarming and are not

**`strict success` = 0.00 %.** Expected, and the reason the metric was split
([D046](DECISIONS.md#d046)). Of the 2 926 rows that reach the goal, **0 meet `ε_v = 0.03`** —
their `|v(T)|` runs 0.052–0.109 m/s, median 0.083. Reaching 100 mm inside 1.5 s means arriving
with speed. Setting V1 poses a *reaching* task; the terminal velocity is kept on every row as a
continuous quantity so this can be revisited from stored data.

**`invalid` = 10.12 %, against v0's 0.88 %.** Higher because the candidate range now reaches
6.5 N, and 6 N on a low-friction drawer is violent. It is concentrated entirely at the top:

| candidate force | invalid |
|---|---|
| 0.5–3.0 N | 0.3 % |
| 3–4 N | 2.2 % |
| 4–5 N | 7.1 % |
| 5–6 N | 24.8 % |
| 6–6.5 N | 51.4 % |

Dominated by `excessive_velocity` (4 413), then lateral (2 587) and orientation (1 614) drift.
**It is not eating the positives**: of the rows landing within `ε_d`, only **12 of 580** in the
pilot were lost to invalidity. The operating region is rejecting high-force overshoots that
would fail on position anyway.

A consequence worth noting and *not* acting on: the 6.0–6.5 N bin yields 0.0 % positives, so
roughly one twelfth of the candidate budget is spent where nothing succeeds. Trimming the range
would be re-tuning a frozen setting, so the observation is recorded rather than applied.

## 3. What the audit checked

All nine gates passed.

| gate | result |
|---|---|
| `identifiers_unique` | pass |
| `probe_references_resolve` | pass |
| `probes_belong_to_one_hidden_state` | pass |
| `repeats_share_a_candidate_grid` | pass |
| `finite_values` | pass |
| `no_privileged_fields_in_model_input` | pass |
| `split_has_no_leakage` | pass |
| `counts_match_the_manifest` | pass |
| `branch_index_decorrelated_from_force` | pass — mean corr **−0.0023 = 0.49σ** against a 3σ gate |

**Candidate budget.** 32 forces per probe gives ≥ 1 positive for **1 519 of 1 536 probes
(98.9 %)** and ≥ 2 for 1 188 (77.3 %); 17 probes (1.1 %) have none. Success against force is a
clean unimodal band peaking at 2.0–3.0 N.

**Split.** Grouped on `xi_id`: 359 / 65 / 88 hidden states → 34 464 / 6 240 / 8 448 rows, with
positive fractions 5.94 / 5.85 / 6.10 % — balanced without being balanced *for*.

**Required force.** Over the 1 519 solvable probes: **0.64–5.51 N, median 2.91, an 8.7× range.**
That is the evidence adaptation is needed; no single force serves this distribution, and the
fixed-force baseline's 8.0 % physical reach success is the same fact from the other end.

## 4. Two outliers, and why three repeats exist

The probe's post-probe displacement is 0.00–42.2 mm, median 6.7, p90 10.3, p99 14.6. The
calibration's 24 states topped out at 13.0 mm, so the tail is wider than the calibration could
see — but only just, and both extremes are **single repeats, not properties of a hidden state**:

| | repeat 0 | repeat 1 | repeat 2 |
|---|---|---|---|
| the 42.2 mm probe (`µ_s` 1.42, `m` 11.60) | 5.72 mm | **42.22 mm** | 5.34 mm |
| breakaway time | 0.083 s | **0.017 s** | 0.100 s |
| the non-mover (`µ_s` 2.40, `m` 10.76) | **0.92 mm, did not break away** | 5.73 mm | 5.78 mm |

One probe in 1 536 (0.07 %) exceeds the calibration's 30 % intrusion gate, and one in 1 536
never broke away. Both are stick-slip transients in the initial contact, and the reason they are
visible *as* transients rather than mistaken for drawer properties is that every hidden state
was probed three independent times. That is what the repeats are for.

## 5. Reproducing

```bash
python scripts/generate_dataset.py --headless --setting v1 \
    --num-xi 512 --repeats 3 --candidates 32 --num_envs 32 --seed 20260902 \
    --dataset-version v1 --output outputs/dataset_v1
python scripts/audit_dataset.py --dataset outputs/dataset_v1
```

Dataset v0 remains regenerable under its own setting with `--setting v0`; nothing about it
changed.
